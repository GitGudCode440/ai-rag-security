# AI RAG Security Threat Prioritizer
An application made for SENTEC Engineer's Code 2025 event. 🚀

## Prerequisites
- Python 3.13 or greater.
- Git & GitHub
- Powershell or POSIX shell

## Usage
Following commands must be run **in order**, to run the application according to host's OS.

### Windows
```powershell
python -m venv .venv
.venv\Scripts\Activate
pip install -r requirements.txt
python .\src\main.py # Run the program
```

### macOS/Linux
```shell
python -m venv .venv 
. ./.venv/bin/activate
pip install -r requirements.txt
python ./src/main.py # Run the program
```
